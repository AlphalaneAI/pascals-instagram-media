# pascals-instagram-media

Öffentliche Ablage für die Instagram-Beiträge von @pascals.solutions. Instagram lädt Videos und Bilder beim Veröffentlichen von hier.
Alles hier ist für die Veröffentlichung bestimmt. Keine privaten Dateien ablegen.

- `PLAN.md`: Strategie, Regeln, Rhythmus (Grundlage für jede neue Woche)
- `JJJJ-wKW/`: fertige Beiträge einer Woche plus `bildunterschriften.md`
- `assets/`: Fotos von Pascal und Erklärfigur (Posen freigestellt als PNG)
- `tools/`: Skripte zum Erzeugen von Reels (`reel.py`), Musik (`music.py`) und Karussells (`carousel.py`)
